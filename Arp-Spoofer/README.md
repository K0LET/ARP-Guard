# 🕵️ Arp-Spoofer

**Arp-Spoofer** is a companion module designed to simulate ARP spoofing attacks. It is intended for testing and validating the functionality of the Arp-Guard system, which detects and protects against such threats.

---

## 📁 Directory Structure
Arp-Spoofer/<br>
└── assets/ # Supporting files and resources for spoofing simulation/<br>

## 🚀 Purpose

The **Arp-Spoofer** module provides:

- Tools or scripts to perform controlled ARP spoofing
- A way to test Arp-Guard’s detection and defense capabilities in a safe environment

---

## 🧪 Usage

> **Note**: This module is intended for use in isolated or lab environments only. Do **not** run spoofing scripts on live or unauthorized networks.

To simulate ARP spoofing:

1. Ensure Arp-Guard is installed and monitoring the network.
2. Run the spoof_gui.py
3. Enter a the nessecry data (IP) 
4. Monitor Arp-Guard's behavior/logs for detection and response.

---

## 🔐 Disclaimer

This tool is for **educational and security testing** purposes **only**. Misuse of ARP spoofing can result in legal consequences. Only use this software in networks you own or are explicitly permitted to test.
